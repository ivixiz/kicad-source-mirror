# KiCAD Source Fork – Part Search Integration

This fork serves as an extension for the [Part Search plugin](https://github.com/ivixiz/KiCAD-Part-Search).  
It modifies the KiCAD schematic editor (EEschema) to allow direct interaction with the external Part Search tool, capture its `stdout` response, parse the result, and automatically populate symbol fields.

---

## Modified Files

The following **five files** have been changed:

## Build Instructions

The project was compiled with **locally built versions** of Abseil and OpenCascade libraries to avoid conflicts with system-installed versions.  

### Example CMake Setup

```bash
# Set build directory
## STEP 1 ##########################################################
BUILD_DIR="./kicad-source-mirror/build"
if [ ! -d "$BUILD_DIR" ]; then
    echo "Build directory does not exist. Creating..."
    mkdir -p "$BUILD_DIR"
fi

cd "$BUILD_DIR" || { echo "Failed to cd into $BUILD_DIR"; exit 1; }
echo "Build folder: $(pwd)"

# Configure KiCAD with local dependencies
cmake ..  -DCMAKE_CXX_COMPILER=clang++-18 \
          -DCMAKE_C_COMPILER=clang-18 \
          -DCMAKE_BUILD_TYPE=RelWithDebInfo\
          -DCMAKE_INSTALL_PREFIX=<path where you want to < make install > after build,for example /usr/local/share/kicad-local> \
          -DOCC_INCLUDE_DIR=<path to opencascade include>/opencascade/ \
          -DOCC_LIBRARY_DIR=<path to opencascade libraries>/opencascade/lib \
          -DCMAKE_PREFIX_PATH=<path to abseil>/abseil/lib/cmake/absl/ \
          -DKICAD_USE_CMAKE_FINDPROTOBUF=ON\
          -DProtobuf_INCLUDE_DIR=/usr/include \
          -DProtobuf_LIBRARY=/usr/lib/x86_64-linux-gnu/libprotobuf.so \
          -DCMAKE_THREAD_LIBS_INIT="-lpthread"
## STEP 2 ##########################################################
# Compile Only EEschema
cd ./kicad-source-mirror/build
make eeschema -j$(nproc)
# Compile All
make -j$(nproc)

## STEP 3 ##########################################################
# Run built KiCAD, not installed. Standart footprints and symbols will not be added.
#!/bin/bash
LD_LIBRARY_PATH=<path to opencascade libraries>/opencascade/lib:$LD_LIBRARY_PATH
KICAD_RUN_FROM_BUILD_DIR=1 ./kicad-source-mirror/build/kicad/kicad

# Run built EEschema Only, not installed. Standart footprints and symbols will not be added.
#!/bin/bash
LD_LIBRARY_PATH=<path to opencascade libraries>/opencascade/lib:$LD_LIBRARY_PATH \
KICAD_RUN_FROM_BUILD_DIR=1 \
./kicad-source-mirror/build/eeschema/eeschema

## STEP 4 (OPTIONAL) ################################################
#Install KiCAD. Standart footprints and symbols will be available.
make install
#or
sudo make install #if /usr/... or other system directories

```
